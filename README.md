# skillswap-cullen

Skill Swap is a project for helping people connect and exchange skills, so they can learn from one another.

## Technologies

- HTML
- CSS
- JavaScript
- Jest

## Features

- Filter skill cards by Programming, Music, and Career categories.
- Calculate total lesson costs from an hourly rate and hours.
- Match skills to a user's category preference and maximum price.

## Tests

Run the unit tests with `npm test`.
